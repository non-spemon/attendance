# 勤怠管理システム（Attendance Management App）
## 概要
スタッフの利便性と管理者の視認性に特化した、シンプルで直感的な勤怠管理アプリケーションです。

**開発背景（プロダクトへの想い）**

前職の医療現場では、勤務管理がアナログな手法や古い慣習で行われており、管理者自身にとってもスタッフの勤務状況が視覚化されていないという課題がありました。<br>
「現場のスタッフは迷わずワンタップで記録でき、管理者は全スタッフの状況を一目で把握・修正できる」状態を目指し、実務での使いやすさを最優先に設計・開発しました。<br>

**主な機能**　<br>
一般ユーザーができること
ユーザー打刻、ログイン機能<br>
管理者（admin）ができること<br>
ユーザー打刻一覧表示、打刻内容編集・削除機能、<br>
スタッフ新規登録、削除機能<br>  

**使用技術**　　

PHP 8.x / MySQL / JavaScript / CSS (Flexbox) / XAMPP

**こだわった点**　

SQLクエリによるデータ集約、レスポンシブデザイン　<br>  　
初めてCRUD機能全てを集約したアプリケーションです。
