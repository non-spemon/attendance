# 勤怠管理システム（Attendance Management App）　”Kintan”
## 概要
スタッフの利便性と管理者の視認性に特化した、シンプルで直感的な勤怠管理アプリケーションです。

**開発背景（プロダクトへの想い）**

前職の医療現場では、勤務管理がアナログな手法や古い慣習で行われており、管理者自身にとってもスタッフの勤務状況が視覚化されていないという課題がありました。<br>
「現場のスタッフは迷わずワンタップで記録でき、管理者は全スタッフの状況を一目で把握・修正できる」状態を目指し、実務での使いやすさを最優先に設計・開発しました。<br>
今回はその例を使用して、CRUD処理やデータ管理を学ぶためにこのアプリを作りました。

**主な機能**　<br>
一般ユーザーができること：<br>
ログイン、ログアウト。出勤、退勤打刻ボタンのクリック（タップ）<br>
管理者（admin）ができること:<br>
ログイン、ログアウト。<br>
ユーザー打刻一覧表示、打刻内容編集・削除<br>
スタッフ新規登録、削除<br>  

**使用技術**　　

PHP 8.x / MySQL / JavaScript / CSS (Flexbox) / XAMPP / GitHub Actions (CI/CD)

**こだわった点**　

### SQLによるデータ操作とDRY原則の徹底:
CRUD機能を網羅し、PDOを用いた安全なデータベース操作を実装。<br>
コードの重複を避けるため、共通処理をfunction.phpに集約し、保守性の高いコーディングを意識しました。<br>

### 実用的なUI/UX:
現場での利用を想定し、レスポンシブデザインを採用。<br>
どのデバイスからでも直感的に打刻できるレイアウトを目指しました。<br>
また、index.phpへのアクセスで即座にログイン画面へ誘導するなど、ユーザーの導線も改善しました。<br>

### 苦労したこと

**今後改修したいこと**
### 管理者用ダッシュボードの拡充:
スタッフ別・月別のフィルタリング機能の追加<br>
### データエクスポート機能:
